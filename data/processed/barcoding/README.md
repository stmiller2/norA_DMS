## Directory Overview

- **[`good_reads/`](good_reads/)** : Sequencing reads after merging and filtering for quality. These files are too large to host on GitHub, but are available on request.
- **[`ref_libs/`](ref_libs/)** : CSVs that map translated amino acid sequences to variant names, referenced in barcode mapping scripts.
- **[`mapping_figs/`](mapping_figs/)** : PNG images illustrating barcoding quality cutoffs for read count and chastity value for each subpool. These are produced by the [barcode mapping scripts](../../../scripts/02_barcoding).
- **[`lookup_tables/`](lookup_tables/)** : Barcode-variant lookup tables for each subpool, plus one combined lookup table for the full library. This is the final product of the barcode mapping process.
