## Directory Overview

- **[`raw/`](raw/)** : Raw sequencing files (.fastq.gz) directly from the sequencer.  
- **[`processed/`](processed/)** : Processed sequencing data for barcoding & barcode validation, drug sensitivity selections, and pH-perturbed selections.
- **[`external/`](external/)** : Non-sequencing data used for clonal validations and other analyses in the publication.

Please see the `README.md` files in each directory for more detailed information.
