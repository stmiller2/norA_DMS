## Directory Overview

These directories contain all images and information necessary to recreate the figures and tables in the paper main text and supplementary.

#### General analysis
- **[`general/`](general/)** : Analyses used in multiple figures/tables (clonal ΔFpH data and pH-perturbed IC50 values; residue distances from binding site and coupling residues; predicted functional hotspot residues; processed and normalized HiBiT membrane-localized abundance data; PyMol sessions illustrating how binding site residues were identified in each conformation).
- **[`clustering/`](clustering/)** : `cluster_assignments.csv` and various clustering QC figures used while identifying good clustering parameters.
#### Figure-by-figure analysis
- **[`fig1/`](fig1/)** : Images, analyses, and PyMol sessions used to create Figure 1.
- **[`fig2/`](fig2/)** : Images, analyses, and PyMol sessions used to create Figure 2.
- **[`fig3/`](fig3/)** : Images, analyses, and PyMol sessions used to create Figure 3.
- **[`fig4/`](fig4/)** : Images and analyses used to create Figure 4.
- **[`fig5/`](fig5/)** : Images and analyses used to create Figure 5.
- **[`fig6/`](fig6/)** : Images used to create Figure 6.
- **[`supplementary/`](supplementary/)** : Images, analyses, PyMol sessions, and other data used to create all supplementary figures and tables.
